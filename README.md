# Local Lead List

A private lead-generation web app for discovering and researching local businesses.

## Goal

Find local businesses by city, surrounding area, and niche, then carefully verify their business information and website status before adding them to a lead list.

## Core Features

- Search businesses by city and surrounding area
- Filter by business niche
- Research businesses without automatically adding them to the lead list
- Highly accurate website/no-website verification
- Phone numbers with click-to-call
- Opening hours and current open/closed status
- Detailed business information
- Lead lists with Excel-style tables
- Quick "20 new leads" feature
- Call tracking and call history
- Google search links for manual verification
- Multi-user access for up to 4 users
- Clean, modern and bright interface
- Evidence and verification information for important lead data

## Accuracy First

Accuracy is the highest priority.

The application must never assume that a business does not have a website simply because a website was not immediately found.

Website status, business identity, phone number, opening hours and other important information should be verified using multiple reliable sources whenever possible.

If information cannot be verified with sufficient confidence, the application should clearly mark it as unverified instead of guessing.

## Development

This project is being developed with Claude Code.

The application should prioritize reliability, verification, maintainability and a clean user experience over development speed.
